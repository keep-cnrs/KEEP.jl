# AGENTS.md — Rocking Arm Model for Kite Power Generation

## Build

Paper (no `latex_out/` folder in the repo: build in a temporary directory, then copy `main.pdf` here):

```sh
latexmk -pdf -interaction=nonstopmode -outdir=<tmp>/build main.tex
cp <tmp>/build/main.pdf .
```

Class option `OptSoft` requires **biber** + `software-biblatex`.
`makeglossaries` needed for acronyms (`myacronyms.sty`).

Figures and tables, from Julia (run from the repo root):

```sh
julia --project=applications/jtcam-tex applications/jtcam-tex/main.jl [sections...] [--fast]
```

- `sections`: `modelling`, `10d`, `analysis`, `optimization` (default: all).
- `--fast`: reduced iteration limits and grids, to test the workflow only; the outputs are then **not** the paper's.
- Writes `figs/<name>.pdf` and `figs/<name>.png`, `tables/table1-5.tex` and the macros `tables/numbers.tex`, `tables/numbers_analysis.tex`; env `JTCAM_OUT_DIR` redirects the outputs (smoke tests).
- `Manifest.toml` is committed (exception in the root `.gitignore`): it pins the package versions of the generated files; CI uses the same Julia version (1.13.4). Update both together.
- Code in `src/` (`helpers.jl`, `modelling.jl`, `numerics_10d.jl`, `analysis.jl`, `optimization.jl`); optimization uses `KEEP.Optimization.optimize(...; max_iter)`.
- Plots math labels need `dvipng`; the font is Libertine (OTF, found with `kpsewhich`).
- `table4.tex` (`tab:parameter_comparison`) carries the warning "values to be checked vs. Alain's computation".
- Generated files are committed. Unused figures are not generated and must not be committed.

CI (`.github/workflows/jtcam-tex.yml`): `compile` on every push/PR touching the paper (uploads `main.pdf`); `figures` on `workflow_dispatch` (input `fast`, default true) or a tag, regenerates `figs/` and `tables/` as an artifact and compiles from them. Committing the regenerated files is a manual step.

- `jtcam_preprint.cls` — journal template.
- `refs.bib`: contains placeholder entries (Salam, Pontzen, Kutz) — replace before submission.

## Physics package notation

Already loaded (`main.tex:7`). Prefer these over raw `\frac`:
- `\vb`, `\vu` — bold/unit vectors
- `\pdv{f}{x}`, `\pdv*{f}{x}` — partial derivatives (star = displayed)
- `\dv{f}{t}`, `\dv*{f}{t}` — total time derivatives
- `\norm{...}`, `\abs{...}` — norms and absolute values
- Only use summations over components if 3rd order tensors are involved, otherwise use linear algebra. Also explore the possibility of using directional derivatives to avoid summations.

## Notation

- Positions: `\vb a` (arm, O to A), `\vb r` (kite, O to K), `\boldsymbol{\ell}` (lines, A to K), with `\vb r = \vb a + \boldsymbol{\ell}`.
- Unit vectors: `\vu a`, `\vu r`, `\hat{\boldsymbol{\ell}}`.
- Number sets and spheres `\mathbf{R}`, `\mathbf{S}^n`; script letters `\mathscr`.

## Custom packages

- `mymacros.sty` — math shorthands: `\vq`, `\dq`, `\ddq`, `\R`, `\vbl`, `\vul`
- `myacronyms.sty` — ODE, DAE, AD, DoF

## Conventions

- `\alter{...}` — WIP note, renders brown. Used for TODOs and placeholders.
- **Text always coherent with generated data** (jb). Never hard-code in the text a number that `main.jl` computes: quote it through a macro of `tables/numbers.tex` (optimization section: `numbers_tex` in `src/optimization.jl`) or `tables/numbers_analysis.tex` (analysis section: `run_analysis` in `src/analysis.jl`), both generated and `\input` in the preamble of `main.tex`; add the macro there if needed. After every regeneration, reread the qualitative claims (increase/decrease, "close to", "no need to adapt") against the new values.
