Reproducing the results

Every figure (figs/*.png, figs/*.pdf), table (tables/table*.tex) and number quoted in the text (tables/numbers.tex, tables/numbers_analysis.tex) is written by main.jl. From the root of the KEEP.jl repository, at commit 2cfaacdcb1a149754d4b7e47f48fc6847394bc30:

git checkout 2cfaacdcb1a149754d4b7e47f48fc6847394bc30
julia --project=applications/jtcam-tex -e 'import Pkg; Pkg.instantiate()'
julia --project=applications/jtcam-tex applications/jtcam-tex/main.jl            # all sections, about 15 min
julia --project=applications/jtcam-tex applications/jtcam-tex/main.jl analysis   # one section: modelling, 10d, analysis, optimization
